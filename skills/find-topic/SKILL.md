# 找到值得寫的題目

使用者這次給的：$ARGUMENTS

這是精簡版：會從你給的材料裡選題，不會上網做競品研究。

## 需要你給我

1. 素材：工作筆記、踩過的雷、最近做成的事，或讀者常問的問題（文字或檔案路徑）。
2. 讀者是誰（有品牌設定就不用說）。

沒給素材時，說明需要什麼，一次問完，不憑空編題目。

## 做法

1. 讀品牌設定（`${CLAUDE_PLUGIN_ROOT}/references/brand.md`）。
2. 從素材裡找三種材料：具體場景、人物加數字、親身反差或具體錯法。只用素材裡真的有的事。
3. 列三個題目，每個寫：一句封面主張、讀者看完能做什麼、用到素材裡哪一段。
4. 推薦一個，說為什麼（跟讀者處境最近、素材最具體、最容易做成成品）。
5. 建議下一步：用 `/ai-staff:make-carousel` 或 `/ai-staff:write-script` 做成成品。

寫法依 `${CLAUDE_PLUGIN_ROOT}/references/writing-rules.md`：不標題黨、不用「我們」「大家」。
