# 先看樣式，再決定

使用者這次給的：$ARGUMENTS

精簡版：預覽是用品牌色與文字排版做的封面圖，沒有 AI 插畫或人像。

## 需要你給我

1. 主題與一句主張。
2. 用在哪：IG 輪播（1080×1350）或短影音封面（1080×1920）。
3. 想要的感覺（可選）：例如安靜、直接、活潑。

## 做法

1. 讀品牌設定；跑 `bash "${CLAUDE_PLUGIN_ROOT}/scripts/check_tools.sh" --for carousel`，缺工具就只交文字版的三款方案。
2. 做三款封面方向，每款一句不同的主標、不同的配色組合（從品牌色挑，或一款暖底、一款深底、一款單色重點）、不同的元件（藥丸標籤、金句、數字放大）。
3. 寫成一個 spec.json，三頁都用 `cover` 頁型；短影音封面把 `size` 改成 `[1080, 1920]`。用 `python3 "${CLAUDE_PLUGIN_ROOT}/scripts/render_carousel.py"` 畫出來，逐張打開看。
4. 把總覽圖給使用者，推薦一款並說明為什麼（手機縮圖是否一秒看懂、跟主題是否相配），其他兩款保留。
5. 使用者選定後，說明下一步：用 `/ai-staff:make-carousel` 以這款為基準做整套。

不替使用者決定最終版本，不把預覽當成定稿。
