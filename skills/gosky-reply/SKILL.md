# Threads 關鍵字回覆（GoSky）

使用者這次給的：$ARGUMENTS

精簡版：整理設定內容與步驟，預設不替使用者操作 GoSky 後台；GoSky 的方案、功能與介面以當下官方頁面為準。

## 需要你給我

1. Threads 貼文內容或連結。
2. 關鍵字。
3. 要送的資源連結（必須真的存在）。
4. 有沒有 GoSky 帳號、Threads 是否已連接（品牌設定有寫就不用說）。

## 做法

1. 讀品牌設定與 `${CLAUDE_PLUGIN_ROOT}/references/writing-rules.md`。
2. 關鍵字清單：主關鍵字、簡體寫法、常見錯字、加標點版本，去重後列成一行。
3. 公開回覆：至少 5 句不重複，口吻像本人，說清楚拿到什麼、去哪拿；資源連結放在回覆裡或引導到指定位置，依使用者指定。Threads 正文與回覆都不放 hashtag。
4. 後台設定步驟：寫成一份清單（建立自動回覆、選貼文、貼關鍵字、貼回覆、設定輪替、儲存、測試），每一步寫「畫面上要看到什麼才算對」。沒有實際進後台就明說步驟是依官方說明整理，介面可能有差。
5. 交付：關鍵字一行、回覆 5 句（程式碼區塊）、步驟清單、測試方法（用另一個帳號留關鍵字看會不會回）。

有瀏覽器工具且使用者明確要求代為設定時，才進後台操作，而且每一步以畫面為準，存檔後讀回。
