# 寫一段能直接念的口播

使用者這次給的：$ARGUMENTS

精簡版：交口播文字與段落標記，不做拍攝表與分鏡。

## 需要你給我

1. 素材：操作紀錄、筆記、想講的重點。
2. 大概長度（秒數或字數），沒說就以 45 到 60 秒、約 180 到 250 字為準。
3. 平台（Reels、Shorts、TikTok）。

## 做法

1. 讀品牌設定，沿用口吻與常用說法。
2. 第一句先講觀眾會得到什麼或正在卡的事，不自我介紹、不「今天來跟大家分享」。
3. 中段講方法：一次一個動作，用口語，句子短，念得出來。數字、工具名只用素材裡真的有的。
4. 做不到、沒測過、有限制的地方直接說，不圓。
5. 收尾一個動作或一句判斷，預設不用問句。
6. 交付格式：每段前面標【開場】【方法 1】【限制】【收尾】，方便剪輯對位；另附一行「建議畫面」給每段。
7. 自己念一遍（在心裡），拗口的改掉；跑 `python3 "${CLAUDE_PLUGIN_ROOT}/scripts/text_check.py"` 檢查。

寫法依 `${CLAUDE_PLUGIN_ROOT}/references/writing-rules.md`。
