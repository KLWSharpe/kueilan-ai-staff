# 把素材剪成短影音

使用者這次給的：$ARGUMENTS

精簡版：做得到的是剪掉不要的段落、裁成 9:16、燒字幕、輸出可播的 mp4。還沒有的：轉場特效、動態貼紙、多機位。

## 需要你給我

1. 毛片檔案路徑（一支或多支）。
2. 目標長度與平台。
3. 逐字稿或字幕檔（沒有的話，看電腦有沒有語音轉字幕工具；沒有就請你提供或先出無字幕版）。
4. 要保留或一定要剪掉的段落（可選）。

## 做法

1. 先跑 `bash "${CLAUDE_PLUGIN_ROOT}/scripts/check_tools.sh" --for video`，把結果列給使用者。缺 ffmpeg 時不停下來：先用逐字稿做剪點清單與字幕草稿，輸出等裝好再做。
2. 用 ffprobe 讀長度、解析度、幀率，確認是橫式還是直式。
3. 有逐字稿或字幕工具時先取得時間碼，再依 `${CLAUDE_PLUGIN_ROOT}/references/writing-rules.md` 的口吻整理剪點清單：保留哪段（起迄時間與那段在講什麼）、剪掉哪段與原因、意思重複的只留最後一次。
4. 字幕斷句照說話的停頓，一句 8 到 18 字，超過 20 字在停頓處切；中英文之間留半形空格。輸出 SRT。
5. 先把剪點清單與字幕草稿給使用者看，確認後再輸出。
6. 用 ffmpeg 依剪點切段、合併、裁成 9:16（橫式素材預設置中裁切，使用者指定人物位置就照指定）、燒字幕，輸出到工作資料夾 `ai-staff-output/<日期>_<主題>/draft.mp4`。
7. 輸出後用 ffprobe 讀回長度與尺寸，抽幾個時間點截圖看字幕有沒有跑掉，再交付。

交付：剪點清單、SRT、草稿 mp4 路徑、沒做到的事。成品不自動排程。
