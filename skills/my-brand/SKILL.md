# 先讓它認識你

目標：產出一份使用者自己的品牌設定檔，讓其他指令寫出來的東西像他本人，而不是像 AI 範本。

使用者這次給的內容：$ARGUMENTS

## 第一步：看有沒有既有設定

依 `${CLAUDE_PLUGIN_ROOT}/references/brand.md` 找設定檔。

- 第一次（兩個位置都沒有）：先用三句話說明這個指令會做什麼、會存到哪裡（`~/.claude/ai-staff/brand.md`），再列 `${CLAUDE_PLUGIN_ROOT}/references/commands.md` 的 13 個指令表，讓使用者知道裝好的東西有哪些。指令寫法依使用者所在的環境：Codex 用 `$my-brand` 這種寫法，Claude Code 用 `/ai-staff:my-brand`；列表時用當下環境的寫法，另一種放括號。然後開始收集資料。
- 已有設定：整份讀出來，用白話摘要目前的設定（帳號、定位、口吻三個形容詞、主色、預設 CTA），問使用者要改哪一項，只改那一項，其他原樣保留。

## 第二步：收集資料，一次問完

使用者已經貼了文章、顏色或商品，就直接分析，不再問同樣的事。缺的用一則訊息一次問完，最多問這五題：

1. 帳號名稱、在哪些平台、一句話定位（教誰、解決什麼）。
2. 三到五篇自己寫過、覺得像自己的貼文（貼文字或檔案路徑都可以）。
3. 讀者是誰、現在卡在哪。
4. 現有商品或服務、購買入口、免費資源（沒有就說沒有）。
5. 常用顏色（HEX 或形容）、浮水印文字、時區、有沒有 ManyChat 或 GoSky 帳號。

對話工具支援選項式提問時可以用，但不要拆成五輪慢慢問。

## 第三步：從文章裡抽出口吻

讀使用者給的文章，整理出：

- 口吻三個形容詞，各附一句原文當證據。
- 常用的說法：抄 3 到 5 句原文，不改寫。
- 慣用結構：怎麼開頭、怎麼收尾、段落長短、有沒有括號碎念、中英夾用、emoji 習慣。
- 不用的詞：文章裡明顯沒出現、或使用者說不喜歡的寫法。

規則：只從給的材料推，推不出來就寫「不確定」。不替使用者編經歷、數字、學員人數或成果。使用者沒給文章時，口吻欄位寫「待校準：還沒有樣本，先用白話與第一人稱」。

## 第四步：寫設定檔

用 `${CLAUDE_PLUGIN_ROOT}/templates/brand-template.md` 的欄位，填成一份完整的 `brand.md`：

- 預設存到 `~/.claude/ai-staff/brand.md`（資料夾不存在就建立）。使用者說只給這個專案用，才存到工作資料夾的 `ai-staff/brand.md`。
- 「更新」日期寫今天。
- 顏色沒給就用範本預設值並標「預設」。
- 寫完整份讀回，確認檔案存在、內容和你要寫的一樣。

## 第五步：交付

給使用者看：

1. 設定檔路徑。
2. 一段摘要：定位一句話、口吻三個形容詞、主色、預設 CTA、時區。
3. 標「不確定」或「待校準」的欄位列出來，請他有空補。
4. 下一步建議：先用 `$make-carousel`（Claude Code 是 `/ai-staff:make-carousel`）做一篇試試，看口吻像不像；不像就回來說「改品牌設定：……」。

不做的事：不替使用者登入任何帳號、不讀他沒給的檔案或資料夾、不把設定檔內容當成之後發布或排程的授權。
