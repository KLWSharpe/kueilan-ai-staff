# 排出做得完的一週

使用者這次給的：$ARGUMENTS

精簡版：產出一張一週計畫表，不自動製作成品，也不進後台排程。

## 需要你給我

1. 這週的目標（例如推一堂課、養一個主題、先維持更新）。
2. 手上素材：做好的圖文、影片、筆記、照片。
3. 一週能投入的時間，以及一定要留白的日子。
4. 平台（沒說就依品牌設定）。

## 做法

1. 讀品牌設定。
2. 先盤素材：每份素材標它能變成什麼（輪播、短片、Threads 短文）、還缺什麼（補拍、確認數字、入口連結）。
3. 依目標排優先：有截止日的先、能直接用現有素材的先、需要補拍的往後。
4. 排成表：日期、平台、內容、用哪份素材、用哪個指令做、預估時間、狀態（可直接做／要補拍／要你確認）。一週不塞超過能做完的量。
5. 把「需要補拍」與「需要你確認」集中成兩個清單放表後面。
6. 建議的發布時段只能來自使用者自己的帳號數據；沒有數據就寫「時段待定」，不拿網路通則冒充建議。

交付後使用者說「開始做第一篇」再接 `/ai-staff:make-carousel` 等指令。
