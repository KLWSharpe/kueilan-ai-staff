# 巡留言，找到要回的人

使用者這次給的：$ARGUMENTS

精簡版：分類與草稿。預設不送出任何回覆，使用者明確說「送出這幾則」才送，而且只送指定的那幾則。

## 需要你給我

1. 貼文連結，或把留言直接貼給我（有瀏覽器工具時可以自己去讀；沒有就請使用者貼）。
2. 這篇的目的（教學、招生、閒聊），有品牌設定就不用多說。
3. 哪些已經回過（可選）。

## 做法

1. 讀品牌設定。
2. 把留言分三類：真正的問題（需要回答）、一般回應（讚美、感謝、表情）、重複或關鍵字留言（例如送禮關鍵字，交給自動化處理）。
3. 真正的問題逐則寫回覆草稿：先回答，再視情況補一句，口吻像本人，不用「感謝您的提問」這種客服腔。已經回過的不再接話。
4. 一般回應給一句通用但不罐頭的回法，不要求每則都回。
5. 可疑或帶風向的留言標出來，建議不回或簡短回，不替使用者吵架。
6. 交付：三類清單、草稿（每則標原留言與草稿）、建議先回哪三則。

不替使用者追蹤、按讚、刪留言或封鎖。
