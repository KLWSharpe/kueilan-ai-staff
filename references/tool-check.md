# 做圖、剪片前先檢查工具

任何會用到本機程式的指令（做圖、剪片、看樣式），在動手之前先跑：

```bash
bash "${CLAUDE_PLUGIN_ROOT}/scripts/check_tools.sh" --for carousel   # 做圖
bash "${CLAUDE_PLUGIN_ROOT}/scripts/check_tools.sh" --for video      # 剪片
```

把結果原樣整理給使用者看：有什麼、缺什麼、怎麼裝。規則：

- 缺工具不是失敗。先把不需要那個工具的部分做完（文案、分頁規劃、剪點清單、規格檔），再列出缺的工具與安裝指令，請使用者裝好後說一聲就接著做。
- 不要替使用者安裝軟體。只給安裝指令或下載頁，由使用者自己執行。
- 「選配」的工具沒裝不用提醒第二次。
- 字型：腳本會回報實際用到哪個繁體中文字型。用的是 Hiragino Sans GB 時，提醒一句字型偏簡體筆畫，裝 Noto Sans TC 會更好看，但不擋流程。
- 瀏覽器與帳號類的工具（Meta 後台、ManyChat、GoSky）沒辦法用腳本檢查。看目前對話有沒有可以操作瀏覽器的工具（Claude in Chrome、內建瀏覽器、電腦控制）；沒有就把要在後台做的事整理成一份清單交給使用者自己點，並明說這次沒有實際操作後台。
