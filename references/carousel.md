# 輪播製作流程

從主題到成圖的完整做法。`/ai-staff:make-carousel` 用這份。

## 1. 準備

1. 讀品牌設定（`brand.md`）。沒有就用預設色與口吻，交付時提醒。
2. 跑工具檢查 `--for carousel`。缺 Python 或 Pillow 時照常寫文案與規格檔，圖片等裝好再畫。
3. 從使用者的話取得：主題、讀者、想讓讀者做什麼、可用的真實素材。主題明確就直接做，不逐項確認。

## 2. 規劃頁面

先在心裡決定：讀者遇到什麼、看完得到什麼、最後做什麼。再排頁序，常見骨架：

1. 封面：一個主訊息，手機縮圖一秒看懂誰遇到什麼、結果是什麼。
2. 問題或場景：讀者現在卡在哪。
3. 到 N：方法、步驟、比較或證據。一頁推進一件事。
4. 收束：一句判斷或金句（只有前面撐得起才放）。
5. CTA：一個動作，說清楚會得到什麼。沒有確認過的入口（留言送禮、購買頁）不能寫成已可用，先寫成提案並標示。

張數由內容決定，刪掉不影響理解、情緒或行動的頁面。同一組要有密度變化，不要每頁都是「兩行標題、三點內文」。

每頁文字規則：圖上用繁體中文，行尾不放逗號、句號；主標短，一頁只有一個主次層級；具體數字和結果值得放大，工具名只負責辨識。

## 3. 寫規格檔

把頁面寫成 JSON，格式見 `python3 "${CLAUDE_PLUGIN_ROOT}/scripts/render_carousel.py" --example`。頁型：`cover`、`text`、`list`、`quote`、`cta`。顏色、浮水印從品牌設定帶入；沒有設定時用範例的預設色。

存放位置：工作資料夾下 `ai-staff-output/<日期>_<主題>/spec.json`（品牌設定另有指定輸出資料夾時照它）。

## 4. 畫圖與檢查

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/render_carousel.py" <spec.json>
```

輸出 `01_cover.png`、`02_text.png`……與 `00_overview.png` 總覽。腳本會回報哪一頁文字放不下。

然後逐張打開大圖看（用讀圖工具實際看，不要只看檔名）：文字有沒有被截、斷行是否自然、主次是否清楚、顏色對比夠不夠、浮水印有沒有壓到字。再看總覽圖，檢查整套節奏。有問題就改 spec.json 再畫，只改一頁用 `--only N`。最多修三輪，仍有問題就如實告訴使用者哪一頁需要人工調整。

## 5. 寫貼文

依 `writing-rules.md` 寫 IG 版 caption（含少量貼題 hashtag）。使用者有 FB 或 Threads 時另寫對應版本。CTA 與圖上的 CTA 一致。跑 `text_check.py`。

## 6. 交付

交付時給：

- 成品資料夾路徑、總覽圖、逐張檔名。
- 完整貼文放在程式碼區塊裡，可以直接複製。
- 哪些地方是提案、待確認（例如 CTA 入口）。
- 一句「想改哪一張跟我說第幾張，或直接說要改的句子」。

修改時只改指定的頁面與句子，不整套重寫。成圖不等於發布，不自動排程。
