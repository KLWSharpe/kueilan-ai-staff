# 排進 Meta Business Suite 的安全做法

`/ai-staff:schedule-post` 用這份。核心不是怎麼點，是怎麼不點錯：「立即發佈」和「排定」、「加強推廣」和「更多選項」只差幾十個像素，點錯就是公開或花錢。

## 開工前要齊的東西

| 項目 | 來源 |
|---|---|
| 要排到哪個粉專與 IG 帳號 | 品牌設定或使用者當次指定；進後台後以畫面上的帳號名為準 |
| 圖片或影片檔案與順序 | 資料夾內檔名 `01_`、`02_`… 零填補，`ls | sort` 的順序就是上傳順序 |
| 已確認的貼文文字 | 使用者核准的版本，逐字用，不再改 |
| 日期、時間、時區 | 使用者指定；時區以品牌設定為準，後台顯示時區要核對 |
| 要不要 FB、IG 分開寫文案 | 使用者說了才分 |

缺任何一項就先問，一次問完。

## 第一步：整理核對表，等 OK

進後台之前，把下面這張表給使用者看：

| 項目 | 內容 |
|---|---|
| 帳號 | 粉專名、IG 帳號名 |
| 平台 | FB、IG 或兩者 |
| 時間 | YYYY-MM-DD HH:MM（時區） |
| 圖片 | 依序列出檔名與張數 |
| 文案 | 完整貼文（程式碼區塊） |
| 撞期 | 同一天已有的排程（先讀後台「已排定」清單） |

說一句：「確認沒問題請回我 OK，我才會排。」沒有 OK 不進入下一步。使用者改東西就更新表再問一次。

## 第二步：進後台（有瀏覽器工具時）

1. 先截圖確認畫面上的帳號是核對表上的帳號。切錯資產就是發到別人的帳號。
2. 走「建立貼文」（Reel 走「建立 Reel」，兩者不同）。
3. 一次多選所有圖片送出；圖片在雲端同步資料夾時先複製到本機暫存資料夾再上傳。
4. 貼上完整文案。Hashtag 放最後，半形 #。
5. 打開排程開關，填日期與時間。
6. 送出前截圖，確認日期、時間、張數、第一張與最後一張。
7. 讀出按鈕文字，確認是「排程」或「排定」，再獨立一次呼叫點下去。
8. 不碰這些按鈕：「立即發佈」「加強推廣」「在廣告管理員中建立廣告」「刪除貼文」。

三條鐵則：驗證和點擊是兩次獨立呼叫；不信語意搜尋給的按鈕標註，只信讀出來的文字；點擊前驗明貼文身分（內文開頭、平台、時間三者吻合）。同一顆按鈕連續失敗兩次就停下來回報。

沒有瀏覽器工具時：把核對表與操作步驟整理成清單交給使用者自己點，明說這次沒有實際操作後台。

## 第三步：讀回對帳

排完後不要用自己的操作紀錄當證據。重新打開「內容 → 貼文和 Reel → 已排定」清單，讀出標題、帳號、時間，和核對表逐列比對，做成表格回報：

| 內容 | 平台 | 指定時間 | 後台實際 | 結果 |
|---|---|---|---|---|

多圖輪播另外打開已排定的貼文預覽，確認張數、第一張、最後一張。對不上就回去修，修完重讀。看一眼「已發佈」最上面幾筆，確認沒有東西被提早發出去。

## 出事了

- 誤發：立刻告訴使用者，不自作主張刪除。刪除要使用者說，而且一律選「移到垃圾桶」（30 天可復原）。
- 誤開廣告流程：退出，不要按任何確認或付款，回報。
